# Campus Beacon
 
## Idea : Centralised Notice/Announcement Board

- **Professors** can quickly publish official notices, upload supporting PDFs or images, and moderate discussions.
- **Students** can view a live feed of notices, filter them by date, and ask questions through threaded comments.
- **Admin** can manage professor accounts to keep the board secure and official.

## Features

### 📢 For Students
- **Live Feed**: A clean, chronological list of all university notices.
- **Quick Filters**: Easily find notices from the last week, month, or quarter.
- **Interactive Comments**: Ask questions or clarify doubts directly under a notice using threaded replies.
- **Document Access**: View or download attached PDFs and images instantly.

### For Professors
- **Easy Publishing**: Create notices using a simple editor that supports formatting (Markdown).
- **File Attachments**: Attach a single PDF or Image to provide more context.
- **Comment Moderation**: Keep the conversation professional by managing student comments.
- **Personal Dashboard**: A private area to manage and track all published notices.


## TechStack
- "backend" : php
- "DBMS" : MySQL
